10. Defend {3}
    The uniqueness rule on (symbol, timestamp) composite works to make sure that
        we only have one entry per symbol at a given time. We don't want it on any
        one column because that would prevent continuous collection. So it has to
        be a composite, and this makes sense. It prevents duplicate collection
        and ensures that we're still able to collect more later. (symbol, price)
        would work too, but in a rare occasion that we have to clear context and
        it's been a while since we've had a price update, that would completely 
        clear our knowledge of the stock temporarily. This way future-proofs and
        ensures that we keep context, while allowing us to always collect the up
        to date information without collecting dups.
